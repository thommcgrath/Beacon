## Usage

1. Any legal software project may use the Beacon Open Hosting API, including those that are freeware, open source, commercial, subscription-based, or enterprise.
2. Beacon / ZAZ Studios does not maintain a registry of API users, and explicit permission is not required.
3. Permission to use the Beacon Open Hosting API is not dependent on inclusion of the logo.
4. The logos files listed below are the only ones that may be used, and the sizing and spacing rules must be followed.

### Sizing And Spacing

When placed alongside other logos, the Beacon Open Hosting API logo must not be shorter vertically than the shortest logo in the group. For instance, if it is placed next to logos measuring 100 and 75 pixels in height, the Beacon Open Hosting API logo should be at least 75 pixels tall. The original aspect ratio must be preserved.

The empty space around the logo should be at least 10% of its largest dimension. For example, if the logo were sized at 256 by 88 pixels, the space around all edges of the logo must be at least 25.6 pixels, equivalent to 27 pixels on all sides.

These rules are applicable to all media types, including websites, video, and print.
